Нэг нэвтрэх түлхүүрээр арван гурван desk, үйлчилгээ. Desk-ээ хөтөч дээр нээх эсвэл JSON API-г өөрийн кодоос дуудаарай — бүх route-ыг доор ажиллах жишээ холбоосын хамт жагсаав.

  1. 01

    Нэвтрэх түлхүүр авах

    Brainy бол хаалттай платформ. Харилцагч, түншүүд түлхүүрээ nyam-ochir@deepbeta.mn-ээс авна. Хөрөнгө оруулагчийн түлхүүр зөвхөн investor порталыг (/investor/*) нээнэ.

  2. 02

    Хөтөч дээр

    Доорх desk эсвэл endpoint-ийн холбоосыг нээнэ үү. Анх орохад нэвтрэх маягт гарна; түлхүүрээ нэг удаа оруулахад тухайн host дээр 24 цагийн турш нэвтэрсэн хэвээр байна.

  3. 03

    Кодоос

    Түлхүүрээ X-Access-Key header-ээр илгээнэ. Нэг удаагийн curl мөрөнд ?access_key=, хуучин хэрэгслүүдэд HTTP Basic (дурын хэрэглэгчийн нэр, нууц үг нь түлхүүр) мөн ажиллана. /health нээлттэй.

QUICK START

export BRAINY_KEY=…   # your access key: keep it in the environment, never in code

# the paper book behind the chart in Results
curl -H "X-Access-Key: $BRAINY_KEY" https://brainy.deepbeta.mn/paperdesk/api/overview

# today's model call for one asset, with backtest-aligned TP / SL
curl -H "X-Access-Key: $BRAINY_KEY" https://brainy.deepbeta.mn/api/inference/GOLD

# the technical desk's full read of one asset
curl -H "X-Access-Key: $BRAINY_KEY" https://technical.deepbeta.mn/api/asset/GOLD

# health of every agent, service, job and pipeline
curl -H "X-Access-Key: $BRAINY_KEY" https://agents.deepbeta.mn/api/agents

# live updates as server-sent events (-N: don't buffer)
curl -N -H "X-Access-Key: $BRAINY_KEY" https://technical.deepbeta.mn/api/stream
import os
import requests

s = requests.Session()
s.headers["X-Access-Key"] = os.environ["BRAINY_KEY"]   # never hard-code the key

book = s.get("https://brainy.deepbeta.mn/paperdesk/api/overview", timeout=60).json()
print(book["equity"]["equity"], book["equity"]["return_pct"])

call = s.get("https://brainy.deepbeta.mn/api/inference/GOLD", timeout=60).json()
tech = s.get("https://technical.deepbeta.mn/api/asset/GOLD", timeout=60).json()
// Node 18+, server side only: never ship the key to a browser
const headers = { 'X-Access-Key': process.env.BRAINY_KEY };

const book = await (await fetch('https://brainy.deepbeta.mn/paperdesk/api/overview', { headers })).json();
console.log(book.equity.equity, book.equity.return_pct);

const call = await (await fetch('https://brainy.deepbeta.mn/api/inference/GOLD', { headers })).json();
const tech = await (await fetch('https://technical.deepbeta.mn/api/asset/GOLD', { headers })).json();
  • Path параметрүүд { } хаалтанд байна. Фокус desk-үүд GOLD, NAS100, WTI, BTCUSD, ETHUSD-г авна; dashboard нь /dashboard/assets-д жагсаасан бүх universe-ийг хамарна.
  • compute route нь хүсэлт ирэхэд бэктест эсвэл sweep ажиллуулдаг тул нэг минут хүртэл үргэлжилж болно. stream route нь server-sent event дамжуулна. file route нь CSV / XLSX файл татна.
  • POST route-ууд төлөв өөрчилнө (демо захиалга, сургалтын ажил, desk-ийн ажиллагаа). Санаатайгаар ашиглаарай.
  • Интерактив баримт бичиг: Swagger · ReDoc · дохионы мөрийн схем · техникийн самбар · шууд самбар · сургалтын GUI.
